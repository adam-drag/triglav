# Planning material

These four files are the original planning material for Triglav, from before the first version was built:

- `START-HERE.md`: the prompt that started the planning.
- `PROJECT-BRIEF.md`: the original requirements.
- `ROLES-AND-WORKFLOWS.md`: the roles and the message board workflow as first described.
- `PLAN.md`: the plan that came out of it, with a short implementation status at the end.

They are kept for background and are not maintained. Parts of them no longer match the code (for example the configuration in `PLAN.md`). `README.md` and `AGENTS.md` in the repository root describe the code as it is now.
